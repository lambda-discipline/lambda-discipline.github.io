Builtins

Every builtin is lowerCamelCase and takes the data it works on last, so partial application reads well: (map (add 1) xs), (filter (lt 0) xs), (split "," line). Lowercase names in a signature are type variables. The same reference is built into the interpreter: run lbd docs [name], or :docs in the REPL.
